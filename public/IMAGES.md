# Visuels à déposer dans /public

Le scaffold référence des images de marque (non incluses pour des raisons de
droits). Dépose les fichiers du client ici, avec ces noms exacts :

- `hero.jpg`              → bandeau d'accueil (table dressée, plats partagés)
- `chef.jpg`             → portrait du chef Jean-Philippe
- `services-hero.jpg`    → bandeau de la page Services
- `service-chef-a-domicile.jpg`
- `service-cocktail-dinatoire.jpg`
- `service-traiteur-evenements.jpg`
- `service-mariage.jpg`
- `contact-hero.jpg`     → bandeau page « Nous joindre » (pâtes fraîches)
- `temoignage-bg.jpg`    → fond clair texturé page Témoignages
- `og-image.jpg`         → image de partage réseaux (1200×630) — utilisée par le schema

Sans image, un repli olive propre s'affiche : rien ne casse.

Recommandé : compresser en WebP/AVIF (ex. Squoosh) ou passer par next/image
plus tard pour de meilleures Core Web Vitals.
